# Bindaş Fındık - E-Commerce & Recipe Platform

An interactive e-commerce storefront and recipe platform dedicated to regional hazelnut products. This project was developed collaboratively as a frontend software engineering practice, focusing on responsive design and user interactions.

## 🚀 Features

* **Product Catalog:** Browse a variety of local products including roasted hazelnuts, hazelnut paste, and hazelnut flour.
* **Shopping Cart Management:** Add items to the cart, adjust quantities, and view dynamic total price updates.
* **Favorites System:** Save your favorite products and recipes for quick access.
* **Dynamic Recipes Section:** Discover delicious desserts like hazelnut cookies, brownies, and Magnolia.
* **Interactive UI:** Smooth side-panel navigation and dynamic filtering built without external libraries.

## 💻 Tech Stack

* **HTML5:** Semantic page structure and layout.
* **CSS3:** Custom styling, Flexbox/Grid layouts, and responsive design.
* **Vanilla JavaScript:** DOM manipulation, cart logic, and interactive components.
